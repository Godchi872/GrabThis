GrabThis 0.1.39 — guided browser setup

The first time GrabThis opens, Browser setup walks you through choosing a browser, opening Extensions, enabling Developer mode, selecting the installed companion folder and checking the desktop connection. Screenshots highlight where to click, are bundled offline and can be enlarged. Instructions are available in English, French and Arabic, in both themes.

Chrome, Edge, Brave and Opera / Opera GX share the Chromium installation flow. Firefox has its own temporary-development-installation steps and a real Firefox screenshot. Permanent Firefox installation still requires a Mozilla-signed package; no unconfirmed store link is presented.

Set up later dismisses first-run setup without blocking ordinary downloads. A sidebar shortcut and reminder let you return. Finish is enabled only after a recent native connection from the selected browser with website access. Browser setup state is stored locally, without changing existing downloads or transfer defaults.

Includes companion 0.1.23. Existing users should reload their unpacked companion after upgrading, then open its popup to refresh connection verification. Setup prepares Chrome, Edge, Firefox, Brave and Chromium native registrations; Opera uses the compatible Chrome registration.

Validation: all five steps, bundled screenshots, language/theme layouts, selected-browser and permission gates, first-run dismissal, reopening and saved completion; actual Chrome and Firefox extension/native handshakes; existing file capture/cancel/fallback/redirect and media behavior; reproducible Firefox source archive. Installer checks use a separate test identity and preserve production browser registrations.

If you already use 0.1.38, choose Settings → Check for updates to download this installer inside the app. Older versions can install GrabThis-0.1.39-Setup.exe manually. Windows x64 preview, unsigned installer. SHA256SUMS.txt accompanies this release.
