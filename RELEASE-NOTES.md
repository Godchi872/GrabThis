GrabThis 0.1.36 — Windows portable preview

Download **GrabThis-0.1.36-windows-x64.zip**, extract the entire folder, then double-click **START-GRABTHIS.cmd**. First run needs internet access to prepare verified video tools (about 105 MB). No .NET SDK or administrator account is needed.

Includes companion 0.1.20. See the included BROWSER-SETUP.txt and FIREFOX-SETUP.txt before connecting your browser. Chrome/Edge use Developer mode; Firefox's unsigned preview is temporary until its signed store release is available.

Highlights: supported pause/resume and automatic connections, automatic eligible file capture with confirmation, floating video MP4/MP3 choices, local video-to-MP3, categories/search/multiple selection, dark/light themes, English/French/Arabic, notifications and tray support.

This preview is unsigned and has no installer. Source website support varies. This download is for Windows x64.

Check the ZIP's SHA-256 against SHA256SUMS.txt if you want to verify your download. GitHub's Source code archives contain the public documentation repository, not the desktop app.
