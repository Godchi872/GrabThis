**[Download for Windows (.exe)](https://github.com/Godchi872/GrabThis/releases/download/v0.1.55/GrabThis-0.1.55-Setup.exe)**

Right-click a web image in Chrome, Edge, Brave, Opera or Firefox and choose **Download image with GrabThis**. Choose its filename and folder, then start the download.

After the installed app opens successfully, it automatically removes cached installers for installed and older versions, including earlier update caches. Newer updates awaiting installation are kept.

Includes Chromium companion **0.1.27**. After updating GrabThis, reload the unpacked extension or close and reopen the browser. Firefox companion **0.1.27** is now available from Mozilla Add-ons and includes the image menu.

Setup still includes the app runtime and video tools for offline installation. Saved language, preferences and download history are preserved. The Windows installer remains unsigned.
